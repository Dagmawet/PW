Project Name: Johnny English (Named based on the Johnny English movie because this program is intended to provide security)

Github Link: Johnny-English

Summary: A program created to simulate a secure 2-way client communication channel through a single server and mutliple clients with a focus on user authentication, data encryption, secure communication, confidentiality, and integrity. Project had a limitation instruction that forbade the use of encryption/decryption libraries which prompted me to create personal encryption blocks. In addition to being secure communication channel, the program was secure against Man-in-the-Middle attacks and Replay attacks.
